# 試験対策資料生成スキル

大学講義の試験対策資料を自動生成します。

## 対応ファイル形式

- **講義資料**: PDF, DOCX, PPTX
- **文字起こし**: TXT, MD
- **シラバス**: PDF, DOCX, TXT, MD

## 使用方法

ユーザーが試験対策について言及したら、以下を確認：

1. シラバスファイルのパス
2. 講義資料フォルダのパス
3. 出力先フォルダ（デフォルト: `./output/`）
4. 出力形式（md / docx / both）

## 処理フロー

### Step 1: ファイルスキャン

```bash
python3 scripts/parse_folder.py <シラバス> <講義フォルダ> --list-only
```

### Step 2: 自動グループ化の確認

JSONの `grouped_by_week` を確認し、ユーザーに表示：

```
=== ファイル自動グループ化結果 ===

【Week 1】
  📄 講義: 第1回民法概論.pdf
  🎤 文字起こし: 0412録音.txt

【Week 2】
  📄 講義: 第2回契約法.pdf
  🎤 文字起こし: 0419録音.txt

【未分類】
  - backup.txt

合計: 講義 X件 / 文字起こし Y件

このグループ化でOKですか？（OK / 修正）
```

### Step 3: 週ごとに処理

各週について：

```bash
python3 scripts/parse_folder.py <シラバス> <講義フォルダ> --week {N} --files "{files}"
```

### Step 4: 試験対策資料を生成

以下の形式で生成：

---

# Week [N] 試験対策資料

## 使用ファイル
- 講義資料: [ファイル名]
- 録音文字起こし: [ファイル名]

## 講義要約
シラバスのトピック・キーワードに沿って、講義資料と文字起こしの内容を統合して構造化要約。

## 試験重要ポイント
試験で問われる可能性が高いポイントを箇条書きで列挙。

## 論述問題（2問）
各問題に以下を含める:
- 問題文
- 模範解答（300-500字）
- 採点基準（配点、基準、部分点ルール）

## 選択問題（3問）
各問題に以下を含める:
- 問題文
- 4つの選択肢（a, b, c, d）
- 正解と解説

## 計算問題（該当する場合のみ）
講義に計算内容がある場合のみ作成。

---

### Step 5: ファイル保存

Writeツールで保存後、Word変換が必要な場合：

```bash
cat {mdファイル} | python3 scripts/save_output.py {output}/week{NN}_試験対策.docx
```

### Step 6: 次の週へ

「Week {N} 完了。次の週を処理しますか？」と確認。

## 重要な制約

- 問題は講義内容のみに基づく（外部知識を前提としない）
- シラバスのトピック・キーワードをカバーする
- 採点基準は具体的かつ明確に
- 講義資料と文字起こしの内容を統合して要約

## 自動グループ化ロジック

文字起こしファイルは以下の優先順位でマッチング：

1. ファイル名の週番号（第1回、Week1など）
2. ファイル名の日付パターン（0412、2024-04-12など）
3. 更新日時の近さ（24時間以内）

## 出力ファイル構成

```
output/
├── week01_試験対策.md
├── week01_試験対策.docx
├── week02_試験対策.md
├── week02_試験対策.docx
...
```
