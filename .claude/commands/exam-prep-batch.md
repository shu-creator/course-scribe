フォルダ内の複数の講義資料から試験対策資料を一括生成します。
週ごとに分割して処理するため、大量のファイル（20ファイル以上）でも対応可能です。

## 手順

### Step 1: ファイル一覧の取得

まず以下のコマンドでフォルダ内のファイルを一覧表示:

```bash
python3 scripts/parse_folder.py "$1" "$2" --list-only
```

### Step 2: 週番号の確認・割り当て

ユーザーに以下の形式でファイル一覧を表示:

```
検出されたファイル:
| # | ファイル名 | 検出週番号 |
|---|-----------|-----------|
| 1 | 講義資料1.pdf | Week 1 |
| 2 | 録音1.txt | - |
| 3 | 講義資料2.pdf | Week 2 |
...

週番号が検出できなかったファイルがあります。
以下のいずれかの方法で週番号を指定してください:

1. **順番で自動割当**: 「順番で」と入力（ファイル更新日順に Week 1, 2, 3...）
2. **手動指定**: 「1:1, 2:1, 3:2, 4:2」のように入力（ファイル番号:週番号）
   - 同じ週に複数ファイルを割り当て可能（講義PDF + 録音を同じ週に）
3. **検出結果を使用**: 「そのまま」と入力（検出できなかったファイルはスキップ）
```

### Step 3: 週ごとに分割処理

**重要**: コンテキスト長の制限を避けるため、週ごとに分割して処理します。

各週について以下を実行:

```bash
python3 scripts/parse_folder.py "$1" "$2" --week {N} --files "{file1},{file2}"
```

そして、その週の試験対策資料を生成:

---

# Week [N] 試験対策資料

## 講義要約
シラバスのトピック・キーワードに沿って講義内容を構造化要約。

## 試験重要ポイント
試験で問われる可能性が高いポイントを箇条書きで列挙。

## 論述問題（2問）
各問題に以下を含める:
- 問題文
- 模範解答（300-500字）
- 採点基準（配点、基準、部分点ルール）

## 選択問題（3問）
各問題に以下を含める:
- 問題文
- 4つの選択肢（a, b, c, d）
- 正解と解説

## 計算問題（該当する場合のみ）
講義に計算内容がある場合のみ作成。

---

### Step 4: 週ごとにファイル保存

各週の生成完了後、すぐにファイルを保存:
- `{output_folder}/week{N}_試験対策.md`
- `{output_folder}/week{N}_試験対策.docx`（Word出力が必要な場合）

```bash
cat {mdファイル} | python3 scripts/save_output.py {output_folder}/week{N}_試験対策.docx
```

### Step 5: 次の週へ進む

「Week {N} の試験対策資料を保存しました。次の週（Week {N+1}）を処理しますか？」

と確認し、ユーザーが続行を希望したら次の週を処理。

---

## 出力ファイル構成

```
output/
├── week01_試験対策.md
├── week01_試験対策.docx
├── week02_試験対策.md
├── week02_試験対策.docx
...
├── week14_試験対策.md
└── week14_試験対策.docx
```

---

**重要な制約**:
- 問題は講義内容のみに基づく（外部知識を前提としない）
- シラバスのトピック・キーワードをカバーする
- 採点基準は具体的かつ明確に
- 同じ週の複数ファイル（講義PDF + 録音文字起こし）は内容を統合して要約

---

## 処理の中断・再開

途中で中断した場合:
「Week {N} から再開」と入力すれば、その週から処理を続行できます。
