フォルダ内の複数の講義資料から試験対策資料を一括生成します。
週ごとに分割して処理するため、大量のファイル（20ファイル以上）でも対応可能です。

**自動機能:**
- 講義資料（PDF/DOCX/PPTX）と録音文字起こし（TXT/MD）を自動分類
- 同じ週のファイルを自動グループ化（ファイル名の日付パターン、更新日時で判定）

## 手順

### Step 1: ファイル一覧の取得

まず以下のコマンドでフォルダ内のファイルを一覧表示:

```bash
python3 scripts/parse_folder.py "$1" "$2" --list-only
```

### Step 2: 自動グループ化の確認

JSONの `grouped_by_week` を確認し、ユーザーに以下の形式で表示:

```
=== ファイル自動グループ化結果 ===

【Week 1】
  📄 講義: 第1回民法概論.pdf
  🎤 文字起こし: 0412録音.txt

【Week 2】
  📄 講義: 第2回契約法.pdf
  🎤 文字起こし: 0419録音.txt

【未分類の文字起こし】
  - recording_backup.txt

---
合計: 講義 14件 / 文字起こし 14件 / 未分類 1件

このグループ化でよろしいですか？
1. **OK**: このまま処理を開始
2. **修正**: グループを手動で調整（例: 「未分類1→Week3」）
3. **順番で**: ファイル更新日順に自動割当
```

### Step 3: 週ごとに分割処理

**重要**: コンテキスト長の制限を避けるため、週ごとに分割して処理します。

各週について、`grouped_by_week` の `all_files` リストを使用:

```bash
python3 scripts/parse_folder.py "$1" "$2" --week {N} --files "{file1},{file2},{transcript1}"
```

そして、その週の試験対策資料を生成:

---

# Week [N] 試験対策資料

## 使用ファイル
- 講義資料: [ファイル名]
- 録音文字起こし: [ファイル名]

## 講義要約
シラバスのトピック・キーワードに沿って、講義資料と文字起こしの内容を統合して構造化要約。

## 試験重要ポイント
試験で問われる可能性が高いポイントを箇条書きで列挙。

## 論述問題（2問）
各問題に以下を含める:
- 問題文
- 模範解答（300-500字）
- 採点基準（配点、基準、部分点ルール）

## 選択問題（3問）
各問題に以下を含める:
- 問題文
- 4つの選択肢（a, b, c, d）
- 正解と解説

## 計算問題（該当する場合のみ）
講義に計算内容がある場合のみ作成。

---

### Step 4: 週ごとにファイル保存

各週の生成完了後、すぐにファイルを保存:
- `{output_folder}/week{NN}_試験対策.md`（NNは2桁: 01, 02...）
- `{output_folder}/week{NN}_試験対策.docx`（Word出力が必要な場合）

```bash
cat {mdファイル} | python3 scripts/save_output.py {output_folder}/week{NN}_試験対策.docx
```

### Step 5: 次の週へ進む

「Week {N} の試験対策資料を保存しました。次の週（Week {N+1}）を処理しますか？」

と確認し、ユーザーが続行を希望したら次の週を処理。

---

## 出力ファイル構成

```
output/
├── week01_試験対策.md
├── week01_試験対策.docx
├── week02_試験対策.md
├── week02_試験対策.docx
...
├── week14_試験対策.md
└── week14_試験対策.docx
```

---

## 自動グループ化のロジック

文字起こしファイルは以下の優先順位で講義資料とマッチング:

1. **ファイル名の週番号**: 両方に「第1回」「Week1」などがある場合
2. **ファイル名の日付**: 両方に「0412」「2024-04-12」などがある場合
3. **更新日時の近さ**: 24時間以内に更新されたファイル同士

---

**重要な制約**:
- 問題は講義内容のみに基づく（外部知識を前提としない）
- シラバスのトピック・キーワードをカバーする
- 採点基準は具体的かつ明確に
- 講義資料と文字起こしの内容を統合して要約

---

## 処理の中断・再開

途中で中断した場合:
「Week {N} から再開」と入力すれば、その週から処理を続行できます。
